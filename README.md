## Context

We built this as a small team for the FIT3161/FIT3162 whole year computer science project at Monash University, aiming to use as much open-source software as possible to create a simple ride-sharing app for University students and staff to utilise. This repository is a monorepo, containing the backend written in Golang and the frontend written in Flutter.

The backend follows the structure of the [Apollo Backend](https://github.com/christianselig/apollo-backend)
